NexusUsers
Cadastro de Usuários Editar Usuário

O NexusUsers é uma aplicação web full-stack desenvolvida para o gerenciamento e administração eficiente de usuários. Criado com Python e Flask, o sistema oferece uma estrutura modular e organizada para manipular dados com segurança e rapidez. Ele serve para centralizar operações essenciais de CRUD (cadastro, visualização, edição e remoção de usuários) de forma prática. Com integração ao banco de dados SQLite via SQLAlchemy e uma interface moderna em dark mode (com efeitos de glassmorphism e layout responsivo), o projeto resolve a gestão de contas com foco em código limpo e excelente experiência visual.
